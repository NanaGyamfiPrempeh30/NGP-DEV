## Context

A small Flask app that runs on AWS Lambda behind API Gateway. All the infrastructure is written in Python with Pulumi. I wrote it up as a tutorial.

## Problem

I wanted to try infrastructure as code in a real programming language, where YAML was the usual choice, and to run a web app with no server to manage.

## What I built

- An S3 bucket holding a text file.
- A Flask app that serves that file, packaged as a Docker container for Lambda.
- An ECR repository, the IAM roles and the Lambda function.
- An API Gateway route that exposes the function over HTTP.

Pulumi's Python SDK creates all of it.

## How it works

1. A request reaches API Gateway.
2. API Gateway calls the Lambda function.
3. The container runs Flask through an adapter and returns the file from S3.

`pulumi up` builds the image, pushes it to ECR and updates the function.

## What broke and how I fixed it

API Gateway returned 500 errors until I set `payload_format_version="1.0"` on the integration. The adapter expects the older event format.

Docker builds failed on my machine until the project folder was shared with Docker Desktop.
