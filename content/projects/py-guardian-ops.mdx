## Context

Py Guardian is a small FastAPI notes API. I used it to show a full path from code to cloud on Azure, and wrote it up as a tutorial.

## Problem

I wanted a pipeline that tests, scans and deploys a container on every push, with no manual steps.

## What I built

- A FastAPI app with notes endpoints and two health endpoints, `/healthz` and `/readyz`.
- A Dockerfile.
- A GitHub Actions workflow that runs the tests, builds the image, scans it with Trivy, pushes it to Azure Container Registry and deploys it to Azure Container Apps.

## How it works

1. I push to `main`.
2. GitHub Actions runs the tests and builds the image.
3. Trivy scans the image.
4. The image goes to the registry.
5. Azure Container Apps pulls it and runs it. Azure uses the health endpoints to check the app.
