## Context

This is not my project. [Aman Pathak wrote it](https://github.com/AmanPathak-DevOps/End-to-End-Kubernetes-Three-Tier-DevSecOps-Project): a three-tier app on AWS EKS with Jenkins, ArgoCD, Prometheus and Grafana. I deployed it on my own AWS account and wrote up the steps.

## Problem

I wanted to run a full DevSecOps pipeline myself, on infrastructure I had to pay for and fix.

## What I built

Only the changes needed to run it somewhere else. My commits start on 27 August 2024.

- Moved the code from GitHub to GitLab and pointed both Jenkins pipelines at the new repos.
- Swapped in my own Terraform state bucket, lock table and key pair.
- Updated image tags in the Kubernetes manifests as the pipelines ran.
- Rewrote the README.

## How it works

Jenkins builds and scans the frontend and backend, pushes the images to ECR and updates the manifests in Git. ArgoCD deploys them to EKS. That design is Aman's.
